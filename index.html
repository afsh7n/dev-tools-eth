How to read this

            
    
              
  • Hash — fingerprint of the unsigned tx. One-way; use it to compare or verify what gets signed.
    • 
              
  • RLP / JSON — the full transaction. Every field (chain, nonce, to, value, data, gas, fees) is recoverable.
    • 
              
  • Signed input — decode also shows the recovered sender and signed tx hash.
    • 
            

            

              Accepted input
              

                0x02…·0xf8…·{ type, … }
              

            

            
Everything runs locally with ethers v6. Never sign a bare hash you cannot tie back to these decoded fields.
